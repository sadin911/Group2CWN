# บันทึกการรีวิวแผนทดสอบ: หัวข้อ 5.2 ข้อมูลราคาตลาดและระบบแชร์สมุดสะสมสาธารณะ

| รหัสทดสอบ (TC) | เกณฑ์การตรวจ | ข้อบกพร่องที่พบ | หลักฐานอ้างอิง | ระดับความรุนแรง | ข้อเสนอแนะแก้ไข | สถานะ |
|---|---|---|---|:---:|---|:---:|
| `TC-PRC-01` | การแสดงผลราคาตลาด | แผนเดิมไม่ได้ทดสอบกรณีการ์ดที่ยังไม่มีราคาตลาดอัปเดต | `pricingStore.ts` | ปานกลาง | ปรับแผนให้ทดสอบการ์ดที่ไม่มีราคาในระบบ โดยต้องแสดงสถานะ N/A หรือขีด ไม่ทำให้ UI พัง | แก้ไขแล้ว |
| `TC-PRC-02` | อัตราแลกเปลี่ยนสกุลเงิน (Currency Selection) | แผนเดิมทดสอบเฉพาะ THB ขาดการสลับเป็น USD/JPY | `types/pricing.ts` รองรับหลายสกุลเงิน | ปานกลาง | เพิ่มการทดสอบสลับสกุลเงินบนหน้าจอ การคำนวณต้องเปลี่ยนตาม Rate ใน store | แก้ไขแล้ว |
| `TC-PRC-03` | ป้องกันข้อมูลต้นทุนรั่วไหล (Zero Leak) | แผนเดิมตรวจเฉพาะข้อความบนหน้า UI ว่าไม่มีคำว่า "ต้นทุน" ซึ่งเสี่ยงเกิด False Pass หากข้อมูลยังแอบส่งมาใน Network JSON | `src/services/sharedCollectionService.ts` ตัด `costPrice` และ `privateNotes` ทิ้งก่อนแชร์ | วิกฤต (Critical) | ปรับปรุงขั้นตอนทดสอบ ให้ดักจับ Network Response JSON ของ `GET /api/share/:id` และ assert ว่าไม่มีคีย์ `costPrice`, `customPrice`, `privateNotes` อยู่ใน Object | แก้ไขแล้ว |
