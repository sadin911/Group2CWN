# ผลสำรวจ Charter C4 · การคำนวณการ์ดที่ขาด (`Missing Cards`) และการคำนวณแบบ Equivalent vs คูปอง

- **ผู้สำรวจ**: Subagent `C4` · **กฎที่รับผิดชอบ**: `BR-13` ถึง `BR-15`
- **ผลการสำรวจจริง (`[O]` เทียบกับ `[D]`)**:
  1. **`BR-13` (หักลบการ์ดที่ขาดเทียบกับสมุดสะสม)**: ทดสอบด้วยบัญชี `U05` (`M01–M03`): เมื่อต้องใช้ `4` ใบและมีในสมุด `5` ใบหรือ `4` ใบ ระบบคืนค่า `missing = 0`; เมื่อมี `3` ใบ คืนค่า `missing = 1` (`✅`)
  2. **`BR-14` (โหมดคำนวณ Equivalent ที่ขอบ `฿999 / ฿1,000 / ฿1,001`)**: ที่ยอด `฿999` (`M04`) ได้การคำนวณการ์ดที่ขาด `฿0` (`netTotalThb = 999`); ที่ยอด `฿1,000` (`M05`) ได้ลด 10% = `฿100` (`netTotalThb = 900`); ที่ยอด `฿1,001` ได้ลด `round(100.1) = ฿100` (`netTotalThb = 901`) (`✅`)
  3. **`BR-15` (โหมด Exact ที่ขอบ `฿1,499 / ฿1,500 / ฿2,000`)**: ที่ `฿1,499` (`M06`) คูปองยังไม่ถึงเกณฑ์ `฿1,500` ระบบใช้ `PARTNER_10PCT` ลด `฿150` (`netTotalThb = 1349`); ที่ `฿1,500` (`M07`) ลดเท่ากันที่ `฿150` ระบบเลือก `PARTNER_10PCT` (`netTotalThb = 1350`); ที่ `฿2,000` (`M08`) ระบบเลือก `PARTNER_10PCT` ที่ลด `฿200` (`netTotalThb = 1800`) (`✅`)
